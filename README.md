# مُحدِّث بيانات الحيازات من GIS

تطبيق Python بواجهة عربية لتحديث ملف البيانات الأساسي من ملف GIS بواسطة **كود القطعة**.

## التشغيل

من داخل هذا المجلد شغّل:

\`\`\`powershell
python -m pip install -r requirements.txt
python main.py
\`\`\`

لا توجد نسخة EXE ولا يحتاج التشغيل إلى أي خطوات تغليف.

## تجربة الاستخدام

1. اختر الملف الأساسي الذي يحتوي على الأعمدة العربية.
2. اختر ملف GIS الذي يحتوي على الأعمدة الإنجليزية.
3. راجع تركيب الأعمدة التلقائي وعدّل أي عمود من القائمة عند الحاجة.
4. اضغط **فحص البيانات أولًا** لمراجعة الأكواد غير المرتبطة والمكررة.
5. اضغط **تحديث وإنشاء نسخة جديدة** بعد المراجعة.

يحفظ التطبيق نسخة جديدة بجانب الملف الأساسي باسم قريب من اسمه، ولا يغيّر الملف الأصلي.

## قواعد التحديث

| الملف الأساسي | ملف GIS |
|---|---|
| اسم الحوض | \`Basin_Name\` |
| كود الحوض | \`Basin_Code\` |
| فدان | \`fadan_survey\` |
| قراط | \`qirat_survey\` |
| سهم | \`sahm_survey\` |
| نوع الاستخدام | \`using_type\` |
| نوع المحصول | \`Crop_type\` |
| مراحل النمو | \`stage_of_growth\` |
| ملاحظات على الحيازة من فريق العمل | \`notes_from_survey\` |

- الخلية الفارغة أو \`NULL\` في GIS تفرّغ الخلية المقابلة في الأساسي.
- إذا أصبح نوع الاستخدام \`بور\` أو \`مباني\`، تُفرّغ الأداة نوع المحصول ومراحل النمو.
- الأكواد المكررة في أي ملف لا تُحدّث تلقائيًا وتظهر في التقرير.
- الملف يجب أن يحتوي على شيت بيانات واحد.

## التنظيم الداخلي

- \`main.py\`: نقطة تشغيل الأداة وتجميع المكونات.
- \`hiyaza_updater/ui.py\`: الواجهة وتجربة الاستخدام.
- \`hiyaza_updater/workbook_store.py\`: قراءة وحفظ ملفات Excel.
- \`hiyaza_updater/update_service.py\`: قواعد الربط والتحديث.
- \`hiyaza_updater/mapping.py\`: اكتشاف وتركيب الأعمدة.
- \`hiyaza_updater/normalization.py\`: توحيد الأكواد والقيم.
- \`test_update_service.py\`: اختبارات قواعد التحديث.

هذا الفصل يحافظ على مسؤولية واضحة لكل جزء ويجعل تعديل الأداة واختبارها أسهل.
