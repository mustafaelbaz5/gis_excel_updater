# مُحدِّث بيانات الحيازات من GIS

أداة Windows بواجهة عربية لتحديث ملف البيانات الأساسي من ملف GIS بالاعتماد على **كود القطعة**.

## ما الذي تنفذه الأداة؟

- تربط الصفوف باستخدام `كود القطعة` في الملفين.
- تركّب تلقائيًا أعمدة ملف GIS الإنجليزية مع الأعمدة العربية في الملف الأساسي.
- تسمح بتغيير العمود المقابل يدويًا قبل التحديث.
- تجعل القيم الفارغة أو `NULL` في GIS خلايا فارغة في الملف الأساسي.
- إذا أصبح `نوع الاستخدام` مساويًا `بور` أو `مباني`، تفرّغ `نوع المحصول` و`مراحل النمو` تلقائيًا.
- لا تحدّث الأكواد المكررة؛ وتعرضها في التقرير لتتم مراجعتها.
- تحفظ نسخة جديدة بجانب الملف الأصلي ولا تعدّل الأصل.

## التشغيل

1. ثبّت Python 3.11 أو أحدث.
2. افتح PowerShell داخل هذا المجلد.
3. نفّذ:

```powershell
python -m pip install -r requirements.txt
python app.py
```

## إنشاء ملف EXE

شغّل `build_exe.bat`. ستجد البرنامج بعد الانتهاء داخل:

`dist\HiyazaGISUpdater\HiyazaGISUpdater.exe`

## الصيغ المدعومة

- `.xlsx` و`.xlsm`: تحفظ في نسخة جديدة مع الاحتفاظ ببنية ملف Excel.
- `.xls` و`.xlsb`: تقرأ وتصدر كنسخة `.xlsx` جديدة.
- `.csv` و`.tsv`: مدعومة كملفات مصدر أو أساسية.

الملف يجب أن يحتوي على شيت بيانات واحد.
